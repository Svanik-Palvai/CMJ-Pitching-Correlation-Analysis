# CMJ-Pitching-Correlation-Analysis

## Overview

This repository documents Python analysis workflows developed in connection with my research on countermovement jump (CMJ) performance and baseball pitching metrics. The research was presented at the National Strength and Conditioning Association (NSCA) National Conference in New Orleans on July 10, 2026.

The project explores relationships between lower-body performance measurements and pitching metrics. It includes correlation analysis and correlation heatmaps, with original notebooks preserved alongside later revisions.

## Project Background

Countermovement jump testing provides measurements of lower-body neuromuscular performance. This project examines how selected CMJ measurements relate to pitching metrics using data collected from baseball pitchers.

Pearson correlation coefficients are used to describe linear relationships between CMJ and pitching variables. These correlations are descriptive and do not establish causation.
